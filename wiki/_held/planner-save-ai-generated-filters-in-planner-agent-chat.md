## What's changing

Microsoft plans to let users save the filters that the Planner Agent generates in its chat, so they can reuse them on their plans. The roadmap description reads: "Save AI-filters generated by the Planner Agent for future use on your plans." Microsoft Learn does not describe this feature yet, so what follows about its behaviour is the roadmap's description and the surrounding product documentation.

Planner Agent chat in premium plans (previously "Copilot in Planner") is an in-app natural language chat. Learn says it lets users request updates to their plans and receive summaries and insights from the plan content. The September 2026 Microsoft 365 Copilot release notes for the separate roadmap item 560532 list chat commands to "update task status or filter your view". Saved filters extend that filtering. Where saved filters are stored, who can see them and whether they can be shared are not documented.

The roadmap record lists the item as In development, with a preview date of July CY2026 and a target date of November CY2026. Both are Microsoft's targets, not commitments. It covers Worldwide (Standard Multi-Tenant) on desktop and web, with General Availability, Preview and Targeted Release phases listed.

## Why it matters

This is a convenience feature inside a chat that users may already have, so it changes little about data, identity or spend. The reason to note it is that it adds saved, AI-built state to a tool whose Copilot features you can only switch off as a whole, not feature by feature.

If nobody acts, users who already have Planner Agent chat will be able to save filters when the feature arrives. Service owners should decide before the November CY2026 target whether that is acceptable alongside the existing Planner Agent access setting, and tell premium plan users what to expect.

## Risk assessment

**Data exposure**

- A saved filter is built from plan content the user can already reach through Planner Agent chat. Microsoft has not documented what is stored with a saved filter or where, so confirm this once documentation exists.
- Learn does not say whether saved filters can be shared with other plan members. Treat sharing as unconfirmed until it is documented.

**Security & identity**

- No new identity or permission model is documented. Learn says users need a Microsoft Copilot licence to access Planner Agent in Planner, and the existing access setting is the only documented way to limit who gets the chat.

**Autonomy & actions**

- The roadmap text describes saving filters, which is a view setting. It does not describe the agent taking actions on tasks. Planner Agent chat itself can request updates to plans, and that capability is governed by the same access setting.

**Change & support**

- Expect questions about why a saved filter returns different tasks over time, because an AI-generated filter is interpreted by the agent. How saved filters behave when plan data changes is not documented.
- Turning off Planner Agent also disables the document authoring skill of Facilitator, per Learn, so a blanket switch-off has a side effect outside Planner.

## Cost and licensing

Microsoft has not published licensing or pricing for saved filters. The Learn page on restricting Planner Agent says users must have a Microsoft Copilot licence to access Planner Agent in Planner.

Planner Agent chat applies to premium plans. The Planner for admins page says a Planner Plan 1 licence is required to create premium plans, and that Planner and Project Plan 3 or Project or Planner Plan 5 licences give access to advanced premium plan capabilities. Whether saved filters need anything beyond these is not yet published.

No meter or cap for this feature is documented at the time of writing (November 2026). The indirect cost is admin time to decide on the access setting and to brief users.

## Scope

The roadmap record lists the item for Worldwide (Standard Multi-Tenant) only, on desktop and web. It does not list any US Government cloud; the record does not say they are excluded.

It applies to users who can reach Planner Agent chat, which Learn describes as available in premium plans. Users need a Microsoft Copilot licence for Planner Agent in Planner. Rollout mechanics beyond the listed release phases (General Availability, Preview and Targeted Release) are not stated. The default state for this feature is not stated.

## Governance guidance

### Before rollout

- Check whether your tenant already has Planner Agent chat on, by running Get-PlannerConfiguration and reading `AllowPlannerCopilot` and `PlannerCopilotAllowedGroupId` (see the controls table).
- Decide whether premium plan users should get saved filters at all, given that the only documented switch covers the whole Planner Agent and chat.
- Watch the Microsoft 365 roadmap item and the Microsoft 365 Copilot release notes for the preview and for any Learn page on saved filters.

### At rollout

- Tell Planner premium plan users that filters the agent builds can be saved, and that results depend on the agent's interpretation of the request.
- Restrict access to a pilot security group with Set-PlannerConfiguration if you want a staged start; allow up to an hour for the change to take effect.

### After rollout

- Re-run Get-PlannerConfiguration to confirm the setting still matches your decision.
- Collect user reports of saved filters returning unexpected tasks and raise them with Microsoft support.

The only documented control is the Planner Agent access setting, which governs Planner Agent and Planner Agent chat together. It is set through PowerShell. Microsoft Learn documents no separate switch for saving filters, and no admin centre page for the Planner access setting at the time of writing (November 2026).

Security group access depends on a valid group ID: Learn says that if the ID is invalid, no users have access even when `AllowPlannerCopilot` is `$true`. Changes can take up to an hour. Agent management in the Microsoft 365 admin center covers Planner Agent in Microsoft Copilot, a different surface from the in-app chat.

## Open questions

- Where are saved filters stored, and who can see them: only the user, or other plan members?
- Is there a separate admin control for saving filters, or does the Set-PlannerConfiguration setting remain the only switch? Watch the Planner turn-off page on Microsoft Learn.
- Does saving filters need a licence beyond the Microsoft Copilot licence that Planner Agent already requires?
- Is the feature on by default for users who already have Planner Agent chat, and does it reach basic plans? Watch Message center and the roadmap item.
