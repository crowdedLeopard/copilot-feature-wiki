## What's changing

Microsoft plans to let users save the filters that the Planner Agent generates in its chat, so they can reuse them on their plans. The roadmap description reads: "Save AI-filters generated by the Planner Agent for future use on your plans." Microsoft Learn does not describe this feature at the time of writing (November 2026), so what follows about its behaviour is the roadmap's description plus the surrounding product documentation.

Planner Agent chat in premium plans (previously "Copilot in Planner") is an in-app natural language chat. Learn says it lets users request updates to their plans and receive summaries and insights from the plan content. The September 2026 Microsoft 365 Copilot release notes for the separate roadmap item 560532 list chat commands to "update task status or filter your view". Where saved filters are stored, who can see them and whether they can be shared are not documented.

The roadmap record lists the item as In development, with a preview date of July CY2026 and a target date of November CY2026. Both are Microsoft's targets, not commitments. It covers Worldwide (Standard Multi-Tenant) on desktop and web, with General Availability, Preview and Targeted Release phases listed.

## Why it matters

This is a convenience feature inside a chat, so on the sources available it changes little about data, identity or spend. It matters because it adds saved, AI-built state to a tool whose Copilot features Microsoft documents a switch for only as a whole, not feature by feature.

Microsoft has not stated whether saved filters will become available automatically to users who already have Planner Agent chat. Service owners should decide before the November CY2026 target whether the existing Planner Agent access setting is enough for them, and tell premium plan users what to expect once Microsoft documents the feature.

## Risk assessment

**Data exposure**

- The roadmap describes saving AI-generated filters for reuse on plans. What data a saved filter holds, where it is stored and whether it can be shared with other plan members are not yet documented, so confirm these once Microsoft publishes them.

**Security & identity**

- No new identity or permission model is documented for saved filters. Learn says users need a Microsoft Copilot licence to access Planner Agent in Planner, and the existing access setting is the only documented way to limit who gets Planner Agent chat.

**Autonomy & actions**

- The roadmap text describes saving filters, not the agent acting on tasks. Planner Agent chat itself can request updates to plans, and that chat is governed by the same access setting.

**Change & support**

- Expect questions if a saved filter shows different tasks after plan data changes; how saved filters behave then is not documented.
- Turning off Planner Agent also disables the document authoring skill of Facilitator, per Learn, so a blanket switch-off has a side effect outside Planner.

## Cost and licensing

Microsoft has not published licensing or pricing for saved filters. The Learn page on restricting Planner Agent says users must have a Microsoft Copilot licence to access Planner Agent in Planner.

Planner Agent chat applies to premium plans. The Planner for admins page says a Planner Plan 1 licence is required to create premium plans. Whether saved filters need anything beyond these is not yet published.

No meter or cap for this feature is documented at the time of writing (November 2026). The indirect cost is admin time to decide on the access setting and to brief users.

## Scope

The roadmap record lists the item for Worldwide (Standard Multi-Tenant) only, on desktop and web. It does not list any US Government cloud; the record does not say they are excluded.

It applies to users who can reach Planner Agent chat, which Learn describes for premium plans. Users need a Microsoft Copilot licence for Planner Agent in Planner. Rollout mechanics beyond the listed release phases (General Availability, Preview and Targeted Release) are not stated, and neither is the default state.

## Governance guidance

### Before rollout

- Check whether your tenant has Planner Agent chat on by running Get-PlannerConfiguration and reading `AllowPlannerCopilot` and `PlannerCopilotAllowedGroupId` (first controls row).
- Decide whether premium plan users should get Planner Agent chat at all, given that the only documented switch covers Planner Agent and its chat together.
- Watch the roadmap item and the Microsoft 365 Copilot release notes for the preview and for any Learn page on saved filters.

### At rollout

- Tell Planner premium plan users that the agent can generate filters and that how saved filters are stored and shared is not yet documented.
- Restrict access to a pilot security group with Set-PlannerConfiguration if you want a staged start, and allow up to an hour for the change to take effect.

### After rollout

- Re-run Get-PlannerConfiguration to confirm the setting still matches your decision.
- Collect user reports of saved filters returning unexpected tasks and raise them with Microsoft support.

The only documented control is the Planner Agent access setting, which governs Planner Agent and Planner Agent chat together and is set through PowerShell.
