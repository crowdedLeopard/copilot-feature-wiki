## This week in one paragraph

34 briefings changed across 5 desks: 13 in Agents & Copilot Studio, 6 in Power Platform, 3 in Security & Compliance, 6 in Admin & Billing, 6 in Microsoft 365 Copilot. 4 carry an "Act now" rating because they are on by default or close to a deadline. 8 are rated high risk, mostly because they move organisational data or let agents act on their own.

## Act now

- **[Copilot Studio: block maker-provided credentials for tool authentication](/features/copilot-studio-block-maker-provided-credentials/)** (High risk). Admins can stop makers choosing their own credentials when they connect tools to agents, forcing end-user authentication so an agent never acts with more access than the person using it.
- **[Microsoft 365 Copilot: federated connectors can create, update and delete in third-party systems](/features/m365-copilot-federated-connectors-write-update-delete/)** (High risk). MCP-based federated connectors can now run write tools from Copilot Chat. Actions run as the user with explicit confirmation, nothing is indexed, and admins see read and write tools per connector in the Microsoft 365 admin center.
- **[Microsoft Teams: AI-generated meeting memory for knowledge retention](/features/teams-ai-generated-meeting-memory/)** (High risk). Teams will store an AI-generated .meeting memory file for recapped meetings so Copilot and Facilitator can answer questions after the transcript expires. On by default, kept five years unless admins or Purview say otherwise.
- **[Microsoft Teams: intelligent recap without saving a transcript](/features/teams-intelligent-recap-without-saving-transcript/)** (Medium risk). Copilot-licensed organisers can get an AI summary of a scheduled meeting without retaining a transcript or recording. The summary is a read-only Word file in the organiser's OneDrive that expires after 120 days by default.

## Agents & Copilot Studio

- **[Copilot Studio: web browsing for agents on the Microsoft Copilot harness](/features/copilot-studio-computer-use-for-web-browsing-on-microsoft-copilot-harness/)**. Prepare, high risk. Copilot Studio agents will browse and interact with websites natively on the Microsoft Copilot harness: navigating, extracting information and downloading files. *(New briefing from roadmap item 576272.)*
- **[Copilot Studio cost controls move into the Microsoft 365 admin center](/features/copilot-studio-cost-management-m365-admin-center/)**. Prepare, medium risk. Copilot Studio environments and agents can be brought under Cost Management spending policies in the Microsoft 365 admin center, so Copilot Credit spend across agents, Cowork and Copilot Chat is governed in one place.
- **[Copilot Studio: MCP-compliant tools in agents and workflows](/features/copilot-studio-mcp-tools-in-agents/)**. Prepare, high risk. Makers can connect Model Context Protocol servers as tools, giving agents live access to external systems. MCP tools ride on Power Platform connectors, so data policies and endpoint filtering are the governing controls.
- **[Copilot Studio: enforce safe sharing by detecting credential oversharing](/features/copilot-studio-safe-sharing-credential-oversharing/)**. Prepare, medium risk. Copilot Studio evaluates an agent's connections at share and publish time and can block agents that rely on embedded maker credentials from reaching end users.
- **[Copilot Studio: share autonomous agents with end users (run-only)](/features/copilot-studio-share-autonomous-agents-run-only/)**. Prepare, high risk. Makers can share trigger-based agents with people who run them under their own credentials. Each user's runs bill Copilot Credits to the hosting environment, and users manage their own connections and trigger settings.
- **[Work IQ: business skills for agents through Work IQ MCP](/features/work-iq-business-skills-to-manage-your-business-processes-in-work-iq-mcp/)**. Prepare, medium risk. Business skills are natural-language process instructions stored in Dataverse that agents discover through Work IQ MCP to follow organisational processes. *(New briefing from roadmap item 573290.)*
- **[Microsoft Agent 365: the control plane for agents](/features/agent-365-control-plane-for-agents/)**. Review, medium risk. Agent 365 is a per-user licensed service that gives IT and security one registry, policy set and observability layer for every agent in the tenant, including agents built outside Microsoft.
- **[Copilot Studio: agents on the Microsoft 365 channel accept files protected by Purview Information Protection labels](/features/copilot-studio-purview-information-protection-labelled-files/)**. Review, medium risk. Users can upload sensitivity-labelled files to Copilot Studio agents in Copilot and Teams. Agents process the content according to the user's and agent's permissions, with label protections enforced end to end.
- **[Copilot Studio: makers can require human approval before an agent runs a tool](/features/copilot-studio-require-human-approval-for-tool-calls/)**. Review, low risk. A per-tool, per-agent toggle pauses the agent and shows an approval card before a gated tool runs, giving a deterministic guard rail for actions such as sending email, closing tickets or making payments.
- **[Work IQ: agents can execute reusable recipes](/features/work-iq-execute-recipes/)**. Review, medium risk. Agents will be able to run reusable Work IQ recipes that coordinate supported tools and actions. *(New briefing from roadmap item 570866.)*
- **[Work IQ: federated connectors for governed access to more data sources](/features/work-iq-federated-connectors/)**. Review, medium risk. Work IQ will be able to use federated connectors to reach additional enterprise data sources under governance. *(New briefing from roadmap item 570670.)*
- **[Work IQ: memory profile path in Work IQ MCP for agents](/features/work-iq-memory-capabilities-expand-to-agents/)**. Review, high risk. A new Work IQ MCP path gives authorised agents access to a user's memory profile, including custom instructions, saved memories and chat-derived memories. *(New briefing from roadmap item 578869.)*

## Power Platform

- **[Dataverse: create agent users with Microsoft Entra agent identity](/features/dataverse-agent-users-entra-agent-identity/)**. Review, medium risk. Agents can be provisioned as Dataverse agent users backed by Entra agent identities, with their own least-privilege security roles and full auditing, instead of borrowing a person's or an application user's access.
- **[Power Platform: secure Dataverse records with column-based filtering](/features/microsoft-power-platform-governance-and-administration-secure-dataverse-record-with-column/)**. Review, medium risk. Dataverse security can grant record access by column values such as region or department rather than by ownership, aimed at reporting and aggregated data. *(New briefing from roadmap item 577860.)*
- **[Power Apps: form fill assistance using Microsoft 365 files in model-driven apps](/features/power-apps-form-fill-assistance-using-m365-files-in-model-driven-apps/)**. Review, medium risk. Form fill assistance in model-driven apps will use Microsoft 365 files as a source for suggested form entries. *(New briefing from roadmap item 576280.)*
- **[Power Apps: modernised Personal settings experience in model-driven apps](/features/power-apps-use-the-modernized-personal-settings-experience/)**. Review, low risk. Model-driven apps get a redesigned Personal settings panel with clearer organisation and navigation, with a button to return to the classic view. *(New briefing from roadmap item 579899.)*
- **[Power Platform: maker guidelines shown inside the Copilot Studio Review pane](/features/power-platform-maker-guidelines-copilot-studio/)**. Review, low risk. Admins can publish a 400-character message, a link and a contact address that Copilot Studio makers see in the Review pane next to their agent's blockers and warnings, per managed environment or environment group.
- **[Power Apps: calendar and card layouts for views in model-driven apps](/features/power-apps-new-view-layout-in-model-driven-apps/)**. Awareness, low risk. Makers can show model-driven app data as a calendar or a stack of cards instead of the default grid, configured in the app designer. *(New briefing from roadmap item 575294.)*

## Security & Compliance

- **[Microsoft 365 Backup: 30-day backup and recovery for Microsoft Entra ID objects](/features/entra-id-backup-and-recovery-30-day/)**. Review, medium risk. Extended 30-day point-in-time recovery of Entra objects (users, groups, app registrations and more) through the Microsoft 365 Backup app and Backup Storage APIs, beyond the 7-day recovery included with Entra ID P1 and P2.
- **[Microsoft Purview DLP: stop Copilot sending sensitive data to external web search](/features/purview-dlp-block-sensitive-data-in-copilot-web-search/)**. Review, low risk. A DLP rule at the Copilot location can detect sensitive information types in a prompt and block web grounding for that response, so Copilot answers from internal data only. Covers Copilot Chat, Microsoft 365 Copilot and Copilot Studio agents in Copilot.
- **[Microsoft Purview: retention based on last accessed date for SharePoint and OneDrive files](/features/purview-retention-last-accessed-sharepoint-onedrive/)**. Review, medium risk. Data Lifecycle Management will be able to start a retention period from when a file was last accessed by a person, not only from creation or last modification, so stale content Copilot might surface can be cleaned up.

## Admin & Billing

- **[Microsoft 365 admin center: agent-level controls for pay-as-you-go](/features/m365-admin-center-agent-level-pay-as-you-go-controls/)**. Prepare, medium risk. Admins can decide which users may use a given agent on a metered basis, which agents are available for consumption billing at all, and which billing policy pays for each agent, starting with declarative agents in Copilot Chat and SharePoint.
- **[Microsoft 365 admin center: Cross-Tenant Orchestrated Migration](/features/m365-admin-center-cross-tenant-orchestrated-migration/)**. Prepare, high risk. Orchestrated cross-tenant migration moves user data and shared data such as mailboxes, OneDrive, Teams and SharePoint between Microsoft 365 tenants. *(New briefing from roadmap item 576273.)*
- **[Microsoft Copilot: delegated publishing of organisation prompts](/features/microsoft-copilot-microsoft-m365-delegated-prompt-publishing-for-organization-prompts/)**. Prepare, medium risk. Admins can delegate organisation prompt publishing to users and groups, who manage tenant-wide prompts in the Prompt Lab without admin centre access. *(New briefing from roadmap item 569425.)*
- **[Microsoft 365 admin center: Copilot Credits usage report for pay-as-you-go in Copilot Chat](/features/m365-admin-center-copilot-credits-usage-report/)**. Review, low risk. A usage report that breaks metered Copilot Chat agent consumption down by user, billing policy, agent and agent-user pair, with alerts for users above 2,000 credits. In preview since May 2025; GA now targeted for April 2027.
- **[Microsoft 365 Backup: Teams channel backup and recovery](/features/m365-teams-channel-backup/)**. Review, low risk. Microsoft 365 Backup will cover teams and channels, so channel messages and files can be restored to a known good point within 30 days after accidental change or compromise. Billing is pay-as-you-go like the rest of Microsoft 365 Backup.
- **[Microsoft 365 Copilot: usage reports for Copilot Search, connectors and agents in US Government clouds](/features/m365-copilot-new-m365-copilot-usage-reports-for-copilot-search-connectors-and-agents-for-u/)**. Awareness, low risk. New admin centre usage reports for Copilot Search, Copilot Connectors and Copilot Agents come to GCC, GCC High and DoD, at organisation and user level. *(New briefing from roadmap item 573170.)*

## Microsoft 365 Copilot

- **[Microsoft 365 Copilot Chat: usage-based billing models in the model selector](/features/m365-copilot-chat-usage-based-billing-models-model-selector/)**. Prepare, medium risk. Users will be able to pick models that bill in Copilot Credits from the model selector in Copilot Chat. Admins must allocate credits through spending policies first, and users can request more when they run out.
- **[Microsoft 365 admin center: rules that automate agent lifecycle management](/features/m365-copilot-agent-lifecycle-management-rules/)**. Review, low risk. Admins can define rules that automatically block risky agents, delete inactive agents and reassign ownerless agents to the owner's manager, from the Agent settings page in the Microsoft 365 admin center.
- **[Microsoft 365 Copilot: exclude specific domains from web grounding](/features/m365-copilot-domain-exclusion-web-grounding/)**. Review, low risk. Admins can list up to 1,000 sites that Microsoft 365 Copilot and Copilot Chat must not use when grounding answers in web content, via a PowerShell script. Cowork honours the same exclusions.
