## Copilot Studio & agents

- **[Copilot Studio: web browsing for agents on the Microsoft Copilot harness](/features/copilot-studio-computer-use-for-web-browsing-on-microsoft-copilot-harness/)**. Prepare, high risk. Copilot Studio agents will browse and interact with websites natively on the Microsoft Copilot harness: navigating, extracting information and downloading files. *(Added governance controls: admin UI paths and API equivalents, sourced to Microsoft Learn)*
- **[Copilot Studio cost controls move into the Microsoft 365 admin center](/features/copilot-studio-cost-management-m365-admin-center/)**. Prepare, medium risk. Copilot Studio environments and agents can be brought under Cost Management spending policies in the Microsoft 365 admin center, so Copilot Credit spend across agents, Cowork and Copilot Chat is governed in one place. *(Added governance controls: admin UI paths and API equivalents, sourced to Microsoft Learn)*
- **[Copilot Studio: MCP-compliant tools in agents and workflows](/features/copilot-studio-mcp-tools-in-agents/)**. Prepare, high risk. Makers can connect Model Context Protocol servers as tools, giving agents live access to external systems. MCP tools ride on Power Platform connectors, so data policies and endpoint filtering are the governing controls. *(Added governance controls: admin UI paths and API equivalents, sourced to Microsoft Learn)*
- **[Copilot Studio: enforce safe sharing by detecting credential oversharing](/features/copilot-studio-safe-sharing-credential-oversharing/)**. Prepare, medium risk. Copilot Studio evaluates an agent's connections at share and publish time and can block agents that rely on embedded maker credentials from reaching end users. *(Added governance controls: admin UI paths and API equivalents, sourced to Microsoft Learn)*
- **[Copilot Studio: share autonomous agents with end users (run-only)](/features/copilot-studio-share-autonomous-agents-run-only/)**. Prepare, high risk. Makers can share trigger-based agents with people who run them under their own credentials. Each user's runs bill Copilot Credits to the hosting environment, and users manage their own connections and trigger settings. *(Added governance controls: admin UI paths and API equivalents, sourced to Microsoft Learn)*
- **[Microsoft Agent 365: the control plane for agents](/features/agent-365-control-plane-for-agents/)**. Review, medium risk. Agent 365 is a per-user licensed service that gives IT and security one registry, policy set and observability layer for every agent in the tenant, including agents built outside Microsoft. *(Added governance controls: admin UI paths and API equivalents, sourced to Microsoft Learn)*
- **[Copilot Studio: agents on the Microsoft 365 channel accept files protected by Purview Information Protection labels](/features/copilot-studio-purview-information-protection-labelled-files/)**. Review, medium risk. Users can upload sensitivity-labelled files to Copilot Studio agents in Copilot and Teams. Agents process the content according to the user's and agent's permissions, with label protections enforced end to end. *(Added governance controls: admin UI paths and API equivalents, sourced to Microsoft Learn)*
- **[Copilot Studio: makers can require human approval before an agent runs a tool](/features/copilot-studio-require-human-approval-for-tool-calls/)**. Review, low risk. A per-tool, per-agent toggle pauses the agent and shows an approval card before a gated tool runs, giving a deterministic guard rail for actions such as sending email, closing tickets or making payments. *(Added governance controls: admin UI paths and API equivalents, sourced to Microsoft Learn)*

Agents can be provisioned as Dataverse agent users backed by Entra agent identities, with their own least-privilege security roles and full auditing, instead of borrowing a person's or an application user's access. *(Added governance controls: admin UI paths and API equivalents, sourced to Microsoft Learn)*

## Governance & security

- **[Microsoft 365 admin center: agent-level controls for pay-as-you-go](/features/m365-admin-center-agent-level-pay-as-you-go-controls/)**. Prepare, medium risk. Admins can decide which users may use a given agent on a metered basis, which agents are available for consumption billing at all, and which billing policy pays for each agent, starting with declarative agents in Copilot Chat and SharePoint. *(Added governance controls: admin UI paths and API equivalents, sourced to Microsoft Learn)*
- **[Microsoft 365 Backup: 30-day backup and recovery for Microsoft Entra ID objects](/features/entra-id-backup-and-recovery-30-day/)**. Review, medium risk. Extended 30-day point-in-time recovery of Entra objects (users, groups, app registrations and more) through the Microsoft 365 Backup app and Backup Storage APIs, beyond the 7-day recovery included with Entra ID P1 and P2. *(Added governance controls: admin UI paths and API equivalents, sourced to Microsoft Learn)*
