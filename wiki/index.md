## Agents & Copilot Studio (8)

- [Copilot Studio: block maker-provided credentials for tool authentication](features/copilot-studio-block-maker-provided-credentials.md) · in-development · risk high · cost none · Act now. Admins can stop makers choosing their own credentials when they connect tools to agents, forcing end-user authentication so an agent never acts with more access than the person using it.
- [Copilot Studio cost controls move into the Microsoft 365 admin center](features/copilot-studio-cost-management-m365-admin-center.md) · in-development · risk medium · cost variable · Prepare. Copilot Studio environments and agents can be brought under Cost Management spending policies in the Microsoft 365 admin center, so Copilot Credit spend across agents, Cowork and Copilot Chat is governed in one place.
- [Copilot Studio: enforce safe sharing by detecting credential oversharing](features/copilot-studio-safe-sharing-credential-oversharing.md) · in-development · risk medium · cost none · Prepare. Copilot Studio evaluates an agent's connections at share and publish time and can block agents that rely on embedded maker credentials from reaching end users.
- [Copilot Studio: MCP-compliant tools in agents and workflows](features/copilot-studio-mcp-tools-in-agents.md) · launched · risk high · cost variable · Prepare. Makers can connect Model Context Protocol servers as tools, giving agents live access to external systems. MCP tools ride on Power Platform connectors, so data policies and endpoint filtering are the governing controls.
- [Copilot Studio: share autonomous agents with end users (run-only)](features/copilot-studio-share-autonomous-agents-run-only.md) · in-development · risk high · cost variable · Prepare. Makers can share trigger-based agents with people who run them under their own credentials. Each user's runs bill Copilot Credits to the hosting environment, and users manage their own connections and trigger settings.
- [Copilot Studio: agents on the Microsoft 365 channel accept files protected by Purview Information Protection labels](features/copilot-studio-purview-information-protection-labelled-files.md) · in-development · risk medium · cost none · Review. Users can upload sensitivity-labelled files to Copilot Studio agents in Copilot and Teams. Agents process the content according to the user's and agent's permissions, with label protections enforced end to end.
- [Copilot Studio: makers can require human approval before an agent runs a tool](features/copilot-studio-require-human-approval-for-tool-calls.md) · in-development · risk low · cost none · Review. A per-tool, per-agent toggle pauses the agent and shows an approval card before a gated tool runs, giving a deterministic guard rail for actions such as sending email, closing tickets or making payments.
- [Microsoft Agent 365: the control plane for agents](features/agent-365-control-plane-for-agents.md) · launched · risk medium · cost high · Review. Agent 365 is a per-user licensed service that gives IT and security one registry, policy set and observability layer for every agent in the tenant, including agents built outside Microsoft.

## Power Platform (2)

- [Dataverse: create agent users with Microsoft Entra agent identity](features/dataverse-agent-users-entra-agent-identity.md) · launched · risk medium · cost none · Review. Agents can be provisioned as Dataverse agent users backed by Entra agent identities, with their own least-privilege security roles and full auditing, instead of borrowing a person's or an application user's access.
- [Power Platform: maker guidelines shown inside the Copilot Studio Review pane](features/power-platform-maker-guidelines-copilot-studio.md) · in-development · risk low · cost none · Review. Admins can publish a 400-character message, a link and a contact address that Copilot Studio makers see in the Review pane next to their agent's blockers and warnings, per managed environment or environment group.

## Security & Compliance (3)

- [Microsoft 365 Backup: 30-day backup and recovery for Microsoft Entra ID objects](features/entra-id-backup-and-recovery-30-day.md) · in-development · risk medium · cost variable · Review. Extended 30-day point-in-time recovery of Entra objects (users, groups, app registrations and more) through the Microsoft 365 Backup app and Backup Storage APIs, beyond the 7-day recovery included with Entra ID P1 and P2.
- [Microsoft Purview DLP: stop Copilot sending sensitive data to external web search](features/purview-dlp-block-sensitive-data-in-copilot-web-search.md) · launched · risk low · cost none · Review. A DLP rule at the Copilot location can detect sensitive information types in a prompt and block web grounding for that response, so Copilot answers from internal data only. Covers Copilot Chat, Microsoft 365 Copilot and Copilot Studio agents in Copilot.
- [Microsoft Purview: retention based on last accessed date for SharePoint and OneDrive files](features/purview-retention-last-accessed-sharepoint-onedrive.md) · in-development · risk medium · cost none · Review. Data Lifecycle Management will be able to start a retention period from when a file was last accessed by a person, not only from creation or last modification, so stale content Copilot might surface can be cleaned up.

## Admin & Billing (3)

- [Microsoft 365 admin center: agent-level controls for pay-as-you-go](features/m365-admin-center-agent-level-pay-as-you-go-controls.md) · in-development · risk medium · cost variable · Prepare. Admins can decide which users may use a given agent on a metered basis, which agents are available for consumption billing at all, and which billing policy pays for each agent, starting with declarative agents in Copilot Chat and SharePoint.
- [Microsoft 365 admin center: Copilot Credits usage report for pay-as-you-go in Copilot Chat](features/m365-admin-center-copilot-credits-usage-report.md) · in-development · risk low · cost none · Review. A usage report that breaks metered Copilot Chat agent consumption down by user, billing policy, agent and agent-user pair, with alerts for users above 2,000 credits. In preview since May 2025; GA now targeted for April 2027.
- [Microsoft 365 Backup: Teams channel backup and recovery](features/m365-teams-channel-backup.md) · in-development · risk low · cost variable · Review. Microsoft 365 Backup will cover teams and channels, so channel messages and files can be restored to a known good point within 30 days after accidental change or compromise. Billing is pay-as-you-go like the rest of Microsoft 365 Backup.

## Microsoft 365 Copilot (6)

- [Microsoft 365 Copilot: federated connectors can create, update and delete in third-party systems](features/m365-copilot-federated-connectors-write-update-delete.md) · launched · risk high · cost none · Act now. MCP-based federated connectors can now run write tools from Copilot Chat. Actions run as the user with explicit confirmation, nothing is indexed, and admins see read and write tools per connector in the Microsoft 365 admin center.
- [Microsoft Teams: AI-generated meeting memory for knowledge retention](features/teams-ai-generated-meeting-memory.md) · in-development · risk high · cost none · Act now. Teams will store an AI-generated .meeting memory file for recapped meetings so Copilot and Facilitator can answer questions after the transcript expires. On by default, kept five years unless admins or Purview say otherwise.
- [Microsoft Teams: intelligent recap without saving a transcript](features/teams-intelligent-recap-without-saving-transcript.md) · launched · risk medium · cost none · Act now. Copilot-licensed organisers can get an AI summary of a scheduled meeting without retaining a transcript or recording. The summary is a read-only Word file in the organiser's OneDrive that expires after 120 days by default.
- [Microsoft 365 Copilot Chat: usage-based billing models in the model selector](features/m365-copilot-chat-usage-based-billing-models-model-selector.md) · in-development · risk medium · cost variable · Prepare. Users will be able to pick models that bill in Copilot Credits from the model selector in Copilot Chat. Admins must allocate credits through spending policies first, and users can request more when they run out.
- [Microsoft 365 admin center: rules that automate agent lifecycle management](features/m365-copilot-agent-lifecycle-management-rules.md) · launched · risk low · cost none · Review. Admins can define rules that automatically block risky agents, delete inactive agents and reassign ownerless agents to the owner's manager, from the Agent settings page in the Microsoft 365 admin center.
- [Microsoft 365 Copilot: exclude specific domains from web grounding](features/m365-copilot-domain-exclusion-web-grounding.md) · rolling-out · risk low · cost none · Review. Admins can list up to 1,000 sites that Microsoft 365 Copilot and Copilot Chat must not use when grounding answers in web content, via a PowerShell script. Cowork honours the same exclusions.
